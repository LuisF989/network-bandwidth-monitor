#  Real-Time Network Bandwidth & Traffic Monitor

Un monitor de tráfico de red en tiempo real desarrollado en Python que calcula el ancho de banda (velocidad de subida y bajada) y el consumo total acumulado de la interfaz activa.

##  Características
* Medición en tiempo real de velocidades de carga y descarga en KB/s y MB/s.
* Registro del volumen total de datos transferidos por sesión.
* Formateo dinámico de unidades y interfaz de consola limpia.

##  Tecnologías Utilizadas
* **Lenguaje:** Python 3.x
* **Librerías:** `psutil`
